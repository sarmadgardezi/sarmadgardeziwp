## 📁 Directory Summary

- **`style.css`**: Theme metadata declaration.
- **`functions.php`**: Bootstrap loader for theme features.
- **`theme.json`**: Global design settings, color palette & typography tokens.
- **`header.php` / `footer.php`**: Document head and footer wrappers.
- **`front-page.php`**: Homepage template orchestrator.
- **`inc/`**: Backend setup, enqueue, and helper functions.
- **`template-parts/`**: Modular layout sections (`global/`, `home/`, `blog/`).
- **`assets/`**: SCSS 7-1 pattern (`assets/scss/`), compiled CSS (`assets/css/main.min.css`), JS scripts, and SVG assets.
- **`screenshot.png`**: WordPress theme preview card (1200x900).

For full technical specifications and phase roadmaps, see **[THEME_STRUCTURE.md](THEME_STRUCTURE.md)**.
